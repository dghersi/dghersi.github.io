# CATÁLOGO DE PROMPTS VERIFICADOS — IMÁGENES DEL CHECKLIST

> Vive en `CHECKLIST ONLINE/PromptImagenes/PlantillasPrompts.md`. Cada fila se añade cuando el usuario aprueba una imagen generada con un prompt de `references/3-Prompt_Imagenes.md`. Nunca se borra una fila — si una imagen se regenera con un prompt distinto, se añade una fila nueva, no se reemplaza la anterior.

## Formato de cada entrada

- **Equipo / Sección:** nombre del equipo + tipo de imagen (Anatomía / Zonificación / Viñeta N).
- **Prompt final usado:** texto completo, con variables ya resueltas.
- **Dimensiones:** ancho × alto en px.
- **Modelo de IA:** el modelo con el que se generó exitosamente (Gemini, DALL-E, Leonardo.AI, Venice.AI, etc.) — no asumir que todos producen el mismo resultado con el mismo prompt.
- **Fecha:** fecha de verificación por el usuario.
