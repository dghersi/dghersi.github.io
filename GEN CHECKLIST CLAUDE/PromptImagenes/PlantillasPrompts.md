# CATÁLOGO DE PROMPTS VERIFICADOS — IMÁGENES DEL CHECKLIST

> Vive en `GEN CHECKLIST CLAUDE/PromptImagenes/PlantillasPrompts.md`. Cada fila se añade cuando el usuario aprueba una imagen generada con un prompt de `references/3-Prompt_Imagenes.md`. Nunca se borra una fila — si una imagen se regenera con un prompt distinto, se añade una fila nueva, no se reemplaza la anterior.
>
> A diferencia de los `Conocimiento_<División>.md`, este catálogo **no tiene contenido de respaldo local** dentro de la skill — mientras no exista en GitHub, simplemente no hay catálogo previo que consultar y cada prompt se genera de cero con las plantillas de `references/3-Prompt_Imagenes.md` (protocolo en su sección 0).

## Formato de cada entrada

- **Equipo / Sección:** nombre del equipo + tipo de imagen (Anatomía / Zonificación / Viñeta N).
- **Prompt final usado:** texto completo, con variables ya resueltas.
- **Dimensiones:** ancho × alto en px.
- **Modelo de IA:** el modelo con el que se generó exitosamente (Gemini, DALL-E, Leonardo.AI, Venice.AI, etc.) — no asumir que todos producen el mismo resultado con el mismo prompt.
- **Fecha:** fecha de verificación por el usuario.

## Nota operativa — Leonardo.AI y dimensiones personalizadas

Leonardo.AI no permite generar directamente en las dimensiones personalizadas que exige el checklist (454×256, 600×256, 300×128, 400×128, etc.) — genera en sus proporciones propias. Flujo verificado: (1) generar la imagen base en Leonardo con el prompt de la plantilla correspondiente, (2) redimensionar/recortar a las dimensiones exactas con Gemini. Registrar ambos modelos en la columna "Modelo de IA" cuando se use este flujo, en el orden en que se usaron.
